# Repository workflow

- When the user authorizes changes, commit and push completed, validated changes
  to the configured GitHub remote. This is the user's standing preference.
- A current request for inspection only, no edits, or no push takes precedence.
- Preserve unrelated local edits. Keep personal recordings, notebook outputs,
  local configuration, and signing keys out of commits. Back up executed
  notebooks locally before clearing their outputs for publication.
